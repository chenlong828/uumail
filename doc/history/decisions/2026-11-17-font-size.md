# 界面与阅读字体大小：机制、偏好与 P2 默认确认（2026-11-17）

## 背景

`REQ-0020`（界面与阅读字体大小可调）在 2026-11-17 完成需求分析（`accepted`），唯一验收场景 `SCN-0015` 由设计节点落为 `designed`。设计输入见 `task-spaces/20261117-071134/{intent.md,brief.md,scenario-drafts.md}`，完整论证与探针见同目录 `design.md` 与 `evidence/font-size-probe/`。

按 `arch-design-spec`，本批为 **P2**：实质性跨文件/跨组件（`CMP-PRES` + `CMP-APP`）、新增兼容性 public 契约（`FontSizePreference`/`FontSizePreferenceStore`）、新增本地 UI 偏好 key、225% 布局调整；不触模块切分/合并、核心契约/schema/数据所有权/分层依赖/热路径，故不升 P1。

## 确认来源与范围

- **无人值守**：本系列任务无 `confirm` 节点、无人在环，发起人未中途逐项回答。
- 依据 `auto-confirm`，以下 D1–D10 为**默认确认（未经人工）**：按 `REQ-0020` 澄清记录、`design.md` 推荐项与默认值自动确认并继续。
- **本记录不是发起人签字，也不得写成「已确认（人）」或「发起人确认」**；评审可独立否决。若评审判 P1 或否决任一子项，按其结论回设计，不复用本记录。
- 确认对象：P2 定级、界面缩放机制、正文缩放机制、偏好形态、菜单入口、100% 恒等口径、225% 预算、空态/按钮处置、测试载体、回归口径。

## 决定

1. **D1 界面缩放 = 环境值 + 显式 scale-aware 字体**：根注入 `\.fontSizePreference` 与 `\.font`（body），显式 `.font(.caption/.headline/.body)` 改 `scaledFont`。100% 返回原语义字体（恒等）；其余档 `NSFont.preferredFont(forTextStyle:)` descriptor 缩放 point size，保持家族/字重。否决 `.dynamicTypeSize`（本机对 `ContentUnavailableView`/Button/ProgressView 尺寸无影响）、`scaleEffect`（卡明确禁止）、全量字号表（同映射复制多份）。
2. **D2 正文缩放 = `WKWebView.pageZoom`**：`MessageWebView.updateNSView` 在 `lastRender` guard 外按档位设 `pageZoom`；`lastRender` 键不含字号。作者显式 `px`、图片、表格随整页缩放；`baseCSS` 13px/1.55、白底、CSP、禁 JS 不改。否决 CSS `font-size` 注入（作者 px 不跟随、需重载/注入）、CSS `zoom` DOM 注入（禁 JS 下不可靠）、重写作者 px（改邮件内容）、混合方案（无收益）。
3. **D3 偏好 = `FontSizePreference` + `FontSizePreferenceStore`**：`Int` raw 100/120/145/175/225；key `appearance.fontSize`；String raw 存储；缺失/损坏/未知回 100；public `init()` 用 `.standard`，internal `init(defaults:)` 供测试；`save` 同值 no-op、不抛、不回滚；会话真源仍是 `UumailApp.@State`。合法整数（int 175）经 `UserDefaults` 字符串桥接按同档接受；其余非法值回 100。
4. **D4 菜单 = 独立 `FontSizeCommands`**：`CommandGroup(after: .sidebar)` + 五项 `Picker("字体大小")`，在 `.commands` 中排在 `ThemeCommands` 之后；不合并 `ThemeCommands`（避免触碰已交付 `SCN-0011`），不新增工具栏控件/设置窗口/快捷键。L2 实测 View 菜单顺序「主题 → 字体大小」相邻；勾选先开父菜单再读（R26）；重复选择 no-op。
5. **D5 100% 恒等与行距**：界面字体在 100% 返回原语义字体；`MessageBodyStyle.baseCSS` 13px/1.55 原样；头部高度 158.5pt 原样（`ViewThatFits` cap 不改变 100%）；不新增 padding/行距/`scaleEffect`。行距随字号调整：界面由字体行高自然跟随，正文 CSS `line-height:1.55` 不改、由 `pageZoom` 等比缩放。
6. **D6 225% 预算**：标签宽 `44×scale`；头部最坏 312.5pt 经 `ViewThatFits` + `ScrollView` cap 220pt，正文视口目标 260pt、验收下限 200pt；状态栏计数 `.layoutPriority(1)`、文案尾部截断；工具栏 7 动作在 900×560 实测全部可见（系统 chrome 不缩放）；列表行高由字体撑开；配置/撰写可滚动。
7. **D7 空态/按钮**：`ContentUnavailableView` 与字符串标题 `Button` 不响应环境字体（实测尺寸比 1.00）。新增内部 `EmptyState`：100% 保留原 `ContentUnavailableView`，>100% 自绘缩放；按钮/`TextEditor` 用显式缩放 label。否决「空态不缩放」（违反 `REQ-0020` 覆盖清单）与「所有档位替换系统组件」（破坏 100% 恒等）。
8. **D8 测试载体**：`PresentationTests` 新增 `FontSizePreferenceStoreTests`；界面/菜单/正文/头部/工具栏/225% 布局用独立 `FontSizeProbe`（编译生产源，不新增 `uumail` 测试 target）；最高 L2，不要求 L3/L4。非 `textSelection` 文本用「同一 `scaledFont`/根环境宿主 + 源码覆盖审计」补足，不把 L1 映射冒充 L2。
9. **D9 回归口径**：100% 只回归 `SCN-0010/0011/0012/0013/0014`；225% 负例（头部 cap、工具栏可达、状态栏、正文视口）只在本景，不改既有卡的数值/行为断言。
10. **D10 级别 = P2**：默认确认（未经人工）；若评审判 P1，先停下回设计/确认，不在实现里扩。

## 范围变更

- 新增 public `FontSizePreference`/`FontSizePreferenceStore`（`CMP-PRES`，兼容性新增）；新增 `CMP-APP` 内部文件 `FontSizeStyle`/`FontSizeCommands`/`EmptyState`。
- 新增本地 UI 偏好 key `appearance.fontSize`（与 `appearance.theme` 同层，不写业务库/Keychain/网络）。
- 新增 `WKWebView.pageZoom` 用法与 `EmptyState` 自绘分支；不新增依赖/target/组件，不改 `Package.swift`、schema、协议、模块切分、数据所有权。
- 回退方式：删除新增文件与调用点，回退 `UumailApp`/视图改动；`appearance.fontSize` key 可保留（无害），无数据迁移。

## 代价 / 影响

- `Presentation` 新增一个 public 枚举与一个本地偏好 store；公开面不含框架/存储类型，属 additive、兼容性变更。
- `pageZoom` 是整页缩放：作者图片/表格/固定宽度布局一起放大；225% 下固定宽度大表可能需要横向滚动，正文仍可滚动、不破坏白底。这是「作者显式 px 也必须缩放」的直接代价。
- 空态在 >100% 走自绘分支，外观不保证与系统 `ContentUnavailableView` 逐像素一致（OQ1）；100% 分支保留原组件。
- 系统工具栏/搜索框/标题栏/菜单栏不缩放（系统能力边界）；工具栏 7 动作在 900×560 仍全部可见。
- `UserDefaults.set` 无同步失败信号，写失败无法强制注入；以「不抛/不回滚 + 会话状态独立」保证，测试覆盖缺失/损坏/持久化/幂等，不伪造失败注入。
- 无 schema/数据迁移；回滚只回代码。

## 未采纳

| 方案 | 理由 |
|---|---|
| UI 用 `.dynamicTypeSize` 近似五档 | 本机实测对 `ContentUnavailableView`/Button/ProgressView 无影响；比例不可控、可能改变系统样式与家族 |
| UI 根 `.scaleEffect` 或截图放大 | `REQ-0020` 明确禁止；模糊、布局不重排 |
| 为每个区域手写字号表 | 同一映射复制十几处，新文本易漏；环境值只有一个变化点 |
| 正文 CSS `font-size`/`zoom` 注入 | 作者内联 px 不跟随；禁 JS 下需重载/注入，改作者样式 |
| sanitizer 重写作者 px | 改邮件内容、规则脆弱，违反边界 |
| 合并进 `ThemeCommands` | 触碰已交付 `SCN-0011`，回归面变大；独立命令已实测相邻 |
| 工具栏新增字号控件 | `REQ-0020` 明确不做；菜单是唯一入口 |
| 空态整体替换为自绘 | 100% 渲染改变，违反恒等 |
| 空态不缩放 | 违反 `REQ-0020` 的界面文字覆盖清单 |
| 新增 `AppTests`/`FontSizeTests` target | 结构变更、成本高；独立 `FontSizeProbe` 已可执行 |
