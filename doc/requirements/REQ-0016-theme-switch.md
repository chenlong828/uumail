# REQ-0016 菜单主题切换

- **ID**：REQ-0016
- **类型**：feature
- **场景叙述**：用户从 macOS 菜单栏的「显示 > 主题」选择「跟随系统」「浅色」或「深色」；应用外观在本次操作内立即切换，当前项有勾选。选择写入本地偏好，退出重开仍生效；首次运行或偏好无效时跟随系统。无论选哪项，邮件正文区仍按 REQ-0015 的规则显示（白底兜底，作者显式背景除外）。
- **价值**：不做则应用只能跟随系统外观；系统深色的用户无法把邮件客户端切成浅色（例如在暗环境下仍希望列表/工具栏用浅色），系统浅色的用户也无法单独把邮件客户端设为深色。macOS 用户对「外观」菜单有稳定预期。
- **非目标**：
  - 不做独立设置窗口/偏好面板；不改 macOS 系统外观，只改本应用。
  - 不做自定义主题、强调色、字体、密度、圆角；不做阅读暗色主题。
  - 不做按时间/环境光自动切换，不做按账号/文件夹/窗口分别设置。
  - 不新增键盘快捷键（菜单项默认行为即可）。
  - 不做跨设备同步主题偏好；不做导入/导出主题配置。
  - 不承诺改变 macOS 顶部菜单栏与系统对话框的外观（由系统控制）；主题只作用于应用窗口与控件。
  - 不改 `uumailctl` 行为；主题只作用于 App。
  - 不改正文白底规则（REQ-0015）。
- **约束**：
  - 入口只在菜单栏；不新增工具栏按钮或设置页。
  - 选择后立即生效，无需重启；不得重建窗口、重置选中/滚动/正文/草稿，不得重新拉正文或触发同步。
  - 作用域为整个应用（当前单窗口；未来多窗口也应一致），配置页与撰写 sheet 一并生效。
  - 偏好持久化到本地 UI 偏好（UserDefaults 或等价），不写业务库/Keychain/网络；默认「跟随系统」；缺失/损坏/未知值回退「跟随系统」。
  - 主题是 UI 偏好，不进入 `MailDomain`/`MailStore`/`Scenes` 业务契约；不新增依赖/target；如需新类型，放 `CMP-APP`/`CMP-PRES` 内。
  - 遵循 macOS 14 最低版本，只用 SwiftUI/AppKit 标准能力，不引第三方库。
  - 当前项勾选状态必须与实际生效值一致；重复选同一项不得重复写偏好或造成闪烁。
  - 与 REQ-0015 正交：强制深色/浅色时正文仍按 REQ-0015 白底兜底；主题只改应用 chrome。
- **影响场景**：
  - `SCN-0011`（已建，`doc/design/scenarios/settings/appearance/theme-switch/`，2026-11-16 转 `designed`）：本卡唯一验收证据。新增「默认跟随系统」「三项切换立即生效并持久化」「系统外观变化时跟随/停止跟随」正例与「无效偏好/写失败/重复选择」反例。
  - `SCN-0010`（已建，`doc/design/scenarios/mail/read/dark-reading-pane/`）：前置条件回归；主题切换后正文仍白，断言归 `SCN-0010`，本卡不重复认领。
  - `SCN-0001`（配置页）、`SCN-0004`（阅读）、`SCN-0006`（撰写）：外观回归，不新增本卡断言；配置页与撰写 sheet 必须随主题变化。
- **澄清记录**：
  - 2026-11-16 首轮需求分析，无人答问；以下按 macOS 习惯与最小范围收敛，设计开工前可改卡：
    - 入口 = macOS 菜单栏「显示 > 主题」子菜单；备选「uumail > 外观」或工具栏菜单。若设计/产品选其它位置，只改入口描述，不改三项选项与验收语义。
    - 选项 = 跟随系统/浅色/深色三选一，默认跟随系统；不做自定义主题。
    - 作用域 = 整个应用（含配置页、邮箱、撰写 sheet、正文之外的 chrome），不是仅当前窗口/当前页面。
    - 持久化 = 本地 UI 偏好，不跨设备；清偏好/重装后回默认。
    - 与 `REQ-0015`：正文白底不受主题选择影响；「深色主题」只改应用 chrome，不改阅读画布。
    - 现状（2026-11-16 代码核对）：`UumailApp` 无 `.commands`、无 `preferredColorScheme`/`NSAppearance`/`UserDefaults`/`@AppStorage`；应用完全跟随系统，没有主题偏好与菜单入口。
