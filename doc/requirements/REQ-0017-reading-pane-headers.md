# REQ-0017 阅读页展示信封头信息

- **ID**：REQ-0017
- **类型**：feature
- **场景叙述**：用户在邮件列表点开一封邮件，右侧阅读区在正文上方显示这封邮件的信封头：发件人、收件人（To）、抄送（有则显示）、主题与时间。头部随选中邮件立即切换；正文尚在加载或加载失败时，头部仍是当前邮件的信封；没有选中邮件时保持「选择一封邮件」占位，不出现空标签。收件人/抄送为空时隐藏对应行；主题为空时显示「(无主题)」；时间取服务器 `DateReceived`（与列表一致）。
- **价值**：不做则右侧只有正文，用户无法在同一处确认这封信是谁发的、发给了谁、主题和时间；遇到相似主题、群发或转发邮件时只能回列表逐项核对，阅读体验不完整，也容易看错对象。
- **非目标**：
  - 不采集/显示真实 `Sent` 发送时间；时间沿用 `DateReceived`，不新增 EAS 字段、协议探针、同步或 schema 改动。若确需真实发送时间，另立需求并先证网关可达性。
  - 不显示 Bcc、Reply-To、Message-ID、会话/线程、重要性、分类、附件数量等头部字段；不解析通讯组、不查 GAL/联系人、不做头像/发件人卡片。
  - 不做可折叠/展开的详细头部，不做点击地址复制、按发件人搜索、回复/转发菜单等交互。
  - 不改列表列与排序、工具栏、窗口标题、正文 HTML 渲染、附件条、已读/删除、同步、发送、搜索。
  - 不改 `MailDomain.Message` 公共字段、`MailStore` schema、`MailGateway`/`Scenes` 契约；不新增依赖/target。
- **约束**：
  - 头部只读当前选中 `Message` 的本地字段（`sender`/`recipients`/`cc`/`subject`/`receivedRaw`），不触网、不触发同步或写命令；打开/切换邮件不增加网络请求。
  - 头部与当前选中一致：切换后不得残留上一封的发件人/收件人/主题/时间；跨文件夹同 `serverID`（搜索）也按复合身份命中正确邮件。
  - 头部在正文 `.loading`/`.loaded`/`.failed` 均可见；无选中时只显示占位，不渲染空头部。
  - 空字段隐藏对应行，不显示空标签/`nil`；主题缺失用「(无主题)」；时间无法解析时按现有 `DisplayFormat.messageDate` 的回退，不崩溃。
  - 长主题/多收件人不得把正文挤到不可用；换行/截断由设计定，正文仍可滚动。
  - 头部随应用主题（深色下不强制白）；`REQ-0015`/`SCN-0010` 的正文白底与 CSP 不回归。
  - 不把真实邮箱地址/主题写入日志或证据；测试用假数据。
- **影响场景**：
  - `SCN-0012`（已建，`doc/design/scenarios/mail/read/message-headers/`，2026-11-16 由 `designed` 转 `verified`）：本卡唯一验收证据；新增「完整头部」「稀疏/空字段」「切换与正文状态」「正文失败反例」断言。
  - `SCN-0004`（已建，`designed`）：回归正文打开、缓存、补拉、截断与 CSP；不新增本卡断言。落 `SCN-0012` 时把 `SCN-0004` 结果句中的「信封」收窄为正文，避免重复认领。
  - `SCN-0010`（已建，`verified`）：回归深色主题下正文白底不被头部改动破坏；不新增断言。

    - 「发送时间」按项目唯一时间源 `DateReceived` 收敛：列表、排序（R10）与阅读头使用同一时间；当前 EAS Sync 实测字段无 `Sent`（`doc/design/components/CMP-EAS/playbook.md` §5.3），真实发送时间不在本卡范围。
