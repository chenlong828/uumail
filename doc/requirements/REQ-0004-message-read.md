# REQ-0004 邮件阅读

- **ID**：REQ-0004
- **类型**：feature
- **场景叙述**：用户点开列表中的一封邮件，1 秒内看到信封与正文；正文未拉取时先显示占位，后台补拉完成后自动替换，无需重新点开。
- **价值**：不做则客户端只能看标题列表，无法判断邮件内容，等于不可用。
- **非目标**：不做富文本回复编辑器（属 REQ-0006/0007）；不做会话聚合；不做正文全文翻译。
- **约束**：打开路径不触网；脚本与远程资源按 T5 策略处理；正文与列表分表。
- **影响场景**：SCN-0004。
- **澄清记录**：2026-11-09 确认 HTML 为主渲染；远程资源默认阻止、单封邮件可临时放行（2026-11-09 确认）。
- **状态**：accepted（2026-11-09 范围确认，见 `history/decisions/2026-11-09-scope-baseline.md`）
- **确认记录**：2026-11-09 首版范围确认，本卡转 `accepted`。
- **验收归属**：SCN-0004 转 `verified`；打开 P95 进性能基线。
