# REQ-0004 邮件阅读

- **ID**：REQ-0004
- **类型**：feature
- **场景叙述**：用户点开列表中的一封邮件，1 秒内看到信封与正文；正文未拉取时先显示占位，后台补拉完成后自动替换，无需重新点开。
- **价值**：不做则客户端只能看标题列表，无法判断邮件内容，等于不可用。
- **非目标**：不做富文本回复编辑器（属 REQ-0006/0007）；不做会话聚合；不做正文全文翻译。
- **约束**：打开路径不触网；脚本与远程资源按 T5 策略处理；正文与列表分表。
- **影响场景**：SCN-0004。
- **澄清记录**：2026-11-09 确认 HTML 为主渲染；远程资源默认阻止、单封邮件可临时放行（2026-11-09 确认）。2026-11-14 列表停留自动已读与服务器已读回写拆到 `REQ-0013`（`SCN-0008`）单独验收；本卡只保留打开与正文渲染，`SCN-0004` 不重复认领已读断言。2026-11-16 深色主题下正文保持白底拆到 `REQ-0015`（`SCN-0010`）单独验收；本卡只保留打开、缓存、补拉、截断与渲染安全，`SCN-0004` 不重复认领阅读底色断言。2026-11-16 阅读页信封头（发件人/收件人/主题/时间）拆到 `REQ-0017`（`SCN-0012`）单独验收；本卡只保留打开、缓存、补拉、截断与渲染安全，`SCN-0004` 不重复认领头信息断言。本卡场景叙述保留首版原文（含「信封」），以本条澄清为准；落 `SCN-0012` 时由设计把 `SCN-0004` 结果句中的「信封」收窄为正文，避免与 `REQ-0017` 重复认领。2026-11-16 阅读区「加载远程图片」开关的位置归 `REQ-0018`（`SCN-0013`）：从正文上方独立行移入窗口主工具栏，仍默认阻止、单封临时放行；本卡保留 T5/CSP 与正文渲染，`SCN-0004` 不重复认领开关位置断言。
