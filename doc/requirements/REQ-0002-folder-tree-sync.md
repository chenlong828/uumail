# REQ-0002 文件夹树同步

- **ID**：REQ-0002
- **类型**：feature
- **场景叙述**：用户打开侧边栏时看到与服务器一致的文件夹树；服务器增删改文件夹后，本地在下次同步时跟随变化，不出现重复或幽灵文件夹。
- **价值**：不做则用户只能在收件箱里看信，草稿、已发送、自建文件夹全部不可达；后续所有「按文件夹」的功能都建在这棵树上。
- **非目标**：不做文件夹排序自定义；不做本地建/删文件夹（探针验证过 `FolderCreate`/`FolderDelete` 可用，但首版不暴露）；不做共享邮箱。
- **约束**：文件夹快照单事务落库；服务器删除不级联删信。
- **影响场景**：SCN-0002。
- **澄清记录**：2026-11-09 确认首版只读文件夹树。

- **确认记录**：2026-11-09 首版范围确认，本卡转 `accepted`。
