# REQ-0010 新邮件通知

- **ID**：REQ-0010
- **类型**：feature
- **场景叙述**：新邮件落库后，用户在系统通知中心看到一条通知与 Dock 角标；点击通知打开对应邮件；关闭通知权限时静默降级。
- **价值**：不做则用户必须手动开关客户端才知道有新信，客户端失去「常驻」意义。
- **非目标**：不做通知分组/摘要；不做按发件人静音规则；不做服务端推送（Ping 未验证，M3 再定）。
- **约束**：通知只由「新邮件落库」事件触发，不在热路径同步发；权限拒绝不报错、不影响收信。
- **影响场景**：待新建（M3 工序创建 `mail/notify/new-mail`）。
- **澄清记录**：2026-11-09 确认通知触发点与权限降级语义。
- **状态**：draft
- **验收归属**：新建场景转 `verified`。
