# REQ-0009 本地搜索

- **ID**：REQ-0009
- **类型**：feature
- **场景叙述**：用户在搜索框输入关键词，列表在本地即时给出命中的邮件（主题、发件人、正文摘要），无网时同样可用。
- **价值**：不做则找一封旧信只能按时间翻列表；邮箱越大越不可用。
- **非目标**：不做远端 `Search`（GAL 与全文搜索实测不可用）；不做复杂查询语法；不做搜索结果导出。
- **约束**：FTS 索引随同步事务增量更新；列表查询不扫正文表；远端失败静默降级为本地结果。
- **影响场景**：待新建（M3 工序创建 `mail/search/local-search`）。
- **澄清记录**：2026-11-09 确认 GAL 不可用，搜索只做本地。
- **状态**：draft
- **验收归属**：新建场景转 `verified`；输入到出结果的延迟进性能基线。
