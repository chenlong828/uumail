# REQ-0041 撰写页顶栏：发送置顶、关闭时存草稿

- **ID**：REQ-0041
- **类型**：`quality`
- **场景叙述**：用户新建、回复、全部回复或转发邮件时，撰写 sheet 的顶栏左侧是一个红色关闭按钮，中间是「新邮件/回复/全部回复/转发」标题，右上是唯一动作、一个大的蓝色「发送」按钮；按 Return 仍是发送。用户点红色关闭或按 Esc 时：没有改动直接关闭；有改动则弹出「存储草稿？」，提供「存草稿」「放弃」「继续编辑」三个选择，默认落在「继续编辑」（Esc），不会因为误关丢失已输入内容。发送、存草稿失败时原因显示在顶栏下方的状态行，sheet 不关闭。
- **价值**：不做的后果——旧撰写 sheet 把「取消 / 状态 / 存草稿 / 发送」放在底部左右两段，与 macOS 自带「邮件」窗口的顶栏语言不一致（发送在窗口顶部右上、关闭在左上、关闭时问存草稿），用户每次都要在底部找按钮，关闭入口还和右上 `xmark` 重复。按 macOS 语言重排后，发送只有一个显眼入口，关闭不再丢内容。
- **非目标**：
  - 不改发送/草稿/取消的数据语义：发送仍只入队、草稿不入队、`hasEdits`、`canSend` 不变。
  - 不改 sheet 宽高计算（`max(阅读窗格, 480)`、`460…820`）、收件人表单与候选浮层、格式栏、编辑器、字号偏好与五档缩放机制。
  - 不做发送失败横幅、Cmd+S 存草稿、发送按钮图标化（椭圆/圆形图标）。
  - 不把撰写从 sheet 改成独立窗口（系统红绿灯只在独立窗口上有）。
  - 不改 schema、不新增 target/依赖、不改 `MailGateway`/`Scenes`/`Outbox`。
- **约束**：
  - 顶栏控件顺序固定：左「关闭」（红点、`xmark`、`.cancelAction`）→ 居中标题 → 右「发送」（`borderedProminent`、`controlSize(.large)`、`.defaultAction`）；底栏与旧 `xmark` 不再存在。
  - 关闭确认文案与按钮：标题「存储草稿？」，按钮「存草稿」（`saveDraft()` 成功才关）、「放弃」（destructive，直接关）、「继续编辑」（`role: .cancel`，默认 Esc）。
  - 状态文本在顶栏下方独立一行，编辑态不占高度；失败时颜色/图标沿用现有 `statusText` 语义。
  - 标题在顶栏内水平居中，按钮固定宽度优先；225%×480 下不重叠。
  - 快捷键不变：Return 发送、Esc 关闭；关闭确认打开时 Esc 落到「继续编辑」。
- **影响场景**：
  - `SCN-0016`（`mail/send/html-reply-compose`）：撰写 sheet 顶栏与关闭确认口径替换为上述内容，新增 `T-SCN-0016-05`（L2 顶栏形态 + 关闭三选一），场景做增量重验。
  - 回归（不新增断言）：`SCN-0015`（五档字号基线：标题/按钮/状态行缩放）、`SCN-0017`（候选浮层锚点不被顶栏高度变化影响）、`SCN-0006`（发送仍只入队）。
- **澄清记录**：
  - 2026-11-25 **人工确认**：撰写页操作按钮全部移到顶部（最初口径），随后按 macOS 邮件截图细化为「只在右上放一个大蓝发送，关闭在左侧」。
  - 2026-11-25 **人工确认**：关闭时有改动询问是否存草稿；默认按钮为「继续编辑」（安全优先）。
