# REQ-0003 收件箱增量同步

- **ID**：REQ-0003
- **类型**：feature
- **场景叙述**：用户启动客户端或等待后台同步后，新到邮件出现在列表顶部；重复同步不产生重复行；服务器游标失步时自动全量重建而不丢信。
- **价值**：不做则列表是空的，用户唯一能做的事（看信）无法发生；同步正确性也是后续发送、搜索、通知的前置。
- **非目标**：不做推送基础设施（Ping 属 M3 且未验证）；不做多账号并行；不做按规则过滤/归档。
- **约束**：批次与 SyncKey 同事务提交；单账号单集合串行；失败保留旧 key。
- **影响场景**：SCN-0003。
- **澄清记录**：2026-11-09 确认窗口 25、`FilterType=0` 为初始值。
- **状态**：accepted（2026-11-09 范围确认，见 `history/decisions/2026-11-09-scope-baseline.md`）
- **确认记录**：2026-11-09 首版范围确认，本卡转 `accepted`。
- **验收归属**：SCN-0003 转 `verified`；`sync_key_age` 与失败率进观测。
