# REQ-0011 离线可用

- **ID**：REQ-0011
- **类型**：quality
- **场景叙述**：用户断网（或服务器不可达）时仍能打开列表、阅读已缓存邮件正文与附件、写草稿并进入待发队列；联网后自动补同步与投递，不打断当前操作。
- **价值**：不做则网络抖动会让整个客户端不可用；这是「桌面客户端」相对网页版的唯一硬价值。
- **非目标**：不做离线搜索未缓存内容；不做跨设备离线同步。
- **约束**：读路径不触网；失败只影响冷路径；冷路径可暂停、可恢复；不丢用户意图（草稿、发送、已读标记）。
- **影响场景**：附着断言（不独立建场景），挂到 SCN-0003、SCN-0004、SCN-0005、SCN-0006 的失败路径上；M1 拆任务时补「断网 30 分钟后恢复」的端到端断言。
- **澄清记录**：2026-11-09 确认作为附着预算挂在业务场景，不单建 DFX 场景；同日范围确认时保留 `draft`——离线断言尚未写进场景卡，待 M1 拆任务时补齐。2026-11-14 已读本地状态不丢见 `REQ-0013`；离线删除不排队、按失败回滚见 `REQ-0014`；两者都不扩大本卡的离线意图队列范围。
- **状态**：draft
- **验收归属**：四个业务场景的离线断言全绿。
