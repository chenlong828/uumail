# REQ-0008 草稿保存

- **ID**：REQ-0008
- **类型**：feature
- **场景叙述**：用户撰写到一半关闭编辑器，内容落到本地草稿；重新打开可继续编辑并发送，服务器不可用时本地草稿不丢。
- **价值**：不做则关窗即丢正文，长邮件场景不可接受。
- **非目标**：不做多端草稿冲突合并（服务器草稿以最后写入为准）；不做自动保存频率可配。
- **约束**：本地草稿先成功再尝试同步 Drafts 集合；服务器失败不回滚本地。
- **影响场景**：待新建（M2 工序创建 `mail/send/draft-save`）。
- **澄清记录**：2026-11-09 确认草稿与 Outbox 共用表、以 `is_draft` 区分，是否拆表留待 M2。
- **状态**：draft
- **验收归属**：新建场景转 `verified`。
