# REQ-0007 回复与转发

- **ID**：REQ-0007
- **类型**：feature
- **场景叙述**：用户在阅读页点「回复」「全部回复」或「转发」，编辑器预填收件人与引用原文，发出的邮件在对方客户端显示为同一会话。
- **价值**：不做则用户只能新建邮件再手动抄地址和原文，日常沟通成本翻倍，且会话关系断裂。
- **非目标**：不做邮件合并；不做自动引用裁剪规则配置；不做「回复时忽略自己的地址」的复杂规则（先按服务器地址列表判断）。
- **约束**：复用 REQ-0006 的发送通道；必须带 `In-Reply-To` / `References` 以保证会话归并；引用原文需转义。
- **影响场景**：SCN-0006（M2 工序在既有场景上新增回复/转发断言，不另立场景）。
- **澄清记录**：2026-11-09 确认回复与发送共用 `SendMail` 通道，仅头不同。
- **状态**：accepted（2026-11-09 范围确认，见 `history/decisions/2026-11-09-scope-baseline.md`）
- **确认记录**：2026-11-09 首版范围确认，本卡转 `accepted`。
- **验收归属**：SCN-0006 新增断言全绿。
