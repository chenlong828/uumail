# REQ-0006 发送邮件

- **ID**：REQ-0006
- **类型**：feature
- **场景叙述**：用户撰写一封邮件（可带附件）点发送后立即回到列表，邮件进入待发队列并在网络可用时自动投递，失败时标红说明原因且最多成功一次。
- **价值**：不做则客户端只能读不能发，无法承担日常沟通；发送被吞或重复发送都会直接损坏用户信任。
- **非目标**：不做富文本模板；不做定时发送；不做大附件云链接。
- **约束**：MIME 以 opaque 原始字节送出；`ClientId` 幂等；入队不等网络。
- **影响场景**：SCN-0006。
- **澄清记录**：2026-11-09 确认成功判据为 `200` + 0 字节 body。
- **状态**：accepted（2026-11-09 范围确认，见 `history/decisions/2026-11-09-scope-baseline.md`）
- **确认记录**：2026-11-09 首版范围确认，本卡转 `accepted`。
- **验收归属**：SCN-0006 转 `verified`。
