# REQ-0031 列表双击浮动阅读窗与就地回复

- **ID**：REQ-0031
- **类型**：`feature`
- **场景叙述**：用户在收件箱（或任一文件夹、搜索结果列表）里**双击**一封邮件，主窗口之上出现一个可移动的阅读浮窗：宽度默认与主窗口阅读区一致，高度默认为主窗口高度的 85%；浮窗里直接显示这封邮件的信封头、会议卡（若是邀请，只读展示）与正文，**远程图片默认直接显示**，顶部一行静态提示说明图片来自外部。浮窗工具栏给出「回复」「全部回复」「转发」；点其中一个，浮窗内容区**就地切换**成撰写界面（收件人、主题、引文已按当前邮件预填），取消或发送后回到阅读态。同一时刻只有一个阅读浮窗：再双击另一封时内容替换并置前，不新开第二个窗口；正在撰写时双击另一封不替换，只置前并提示。
- **价值**：不做的后果——现在读第二封或对照两封必须占用主窗口阅读区；列表双击是 macOS 邮件类应用的默认动作，当前双击无反应，用户会反复尝试。回复必须先选中邮件再用主窗口工具栏弹 sheet，弹 sheet 又盖住列表。会议邀请这类"打开说明很重要"的邮件，候选做法是每次手动点「加载远程图片」，而浮窗默认放行直接给到可读内容。
- **非目标**：
  - 不做多开（一封一个窗口），不做标签页、不做左右分栏对照。
  - 不改列表单击行为、不改主窗口三栏结构、不改主窗口工具栏与现有撰写 sheet。
  - 浮窗不搬附件条；**主窗口阅读区的远程图片仍默认阻止**——浮窗默认放行只限浮窗，不扩散到主窗口、也不扩散到撰写编辑器。
  - 不做打印、导出、移到文件夹、删除、标记未读、定时发送；不新增邮件列表右键菜单。
  - 不改 schema、不新增 target、不新增第三方依赖；唯一跨层新增是按引用取单封的读面（同批新增，口径见决策 D12）。
- **约束**：
  - **单例**：同一时刻至多一个阅读浮窗；双击另一封 → 同一窗口替换内容并置前。浮窗处于撰写态时**不替换**内容（避免丢草稿），只把窗口置前并提示「正在撰写中，请先取消或发送」。
  - **默认尺寸与记忆**：宽 = 主窗口阅读区宽度（沿用 `REQ-0021` 撰写 sheet 的宽度口径），下限 480pt；高 = 主窗口高度 × 85%，下限 460pt，且不超过主窗口所在屏幕的可用高度。窗口可移动、可缩放；用户调整后的尺寸与位置被记住（跨启动），下次打开沿用。
  - **内容同源**：信封头 + 会议卡 + 正文，走与阅读区相同的读取路径（缓存优先、正文未缓存先占位后补拉），打开不额外触网；正文补拉失败时显示占位与重试，不静默空白。会议卡在浮窗内**只读、不开放任何按钮**（导出入口归日历入口的工具栏，见 `REQ-0032`）。
  - **远程图片**：浮窗阅读态默认允许加载远程资源；顶部显示一条静态提示（不阻断、不需确认），说明图片来自发件人服务器。主窗口阅读区仍默认阻止并保留既有放行开关。
  - **已读**：打开浮窗即把该封标为已读——本地先落库、服务器尽力回写；本地失败给中文提示、回写失败静默不重试（沿用 `REQ-0013` 的失败语义）。主窗口列表随之刷新为已读。
  - **就地撰写**：复用现有 `ComposeViewModel`/撰写界面；收件人、主题、引文与主窗口「回复」「全部回复」「转发」一致；取消、发送、存草稿后回到阅读态；浮窗在撰写态被关闭时沿用「放弃这封邮件？」确认。撰写编辑器内的引用正文仍按默认阻止远程资源。
  - **键盘**：列表中选中的行按 Enter 或空格同样打开浮窗（与双击等价），与双击共享同一条打开路径。
  - **互不阻塞**：浮窗开着时主窗口仍可切换选中、同步、删除、打开日历；浮窗不改变主窗口选中项。
  - 中文文案、失败可重试；不出现原始存储/网络错误串。
- **影响场景**：
  - **新建 `SCN-0025`（`mail/read/floating-reader`）**：认领「双击/Enter/空格出窗与默认尺寸」「就地回复」「单例替换与撰写态拒绝」「已读即时置读」「远程图片默认显示 + 静态提示」「撰写态关闭确认」（3 正 1 反）。
  - 回归（不新增断言，不作为本卡验收证据）：`SCN-0004`（正文补拉与渲染）、`SCN-0012`（信封头）、`SCN-0023`（会议卡）、`SCN-0006`/`SCN-0007`（回复 / 全部回复种子）、`SCN-0016`（撰写 sheet 与格式栏）、`SCN-0013`（主窗口远程图片默认阻止与开关）。
  - 关联：`REQ-0032` 复用同一浮窗，只换入口与工具栏；`REQ-0033` 改列表加载窗口。
- **澄清记录**：
  - 2026-11-24 **人工确认**：浮窗形态 = **单例**（同一时刻一个，替换内容并置前），不做多开。
  - 2026-11-24 **人工确认**：尺寸口径 = 宽取阅读区宽度、高取主窗口高度的 85%（原话「高度 85% 窗体宽度」按此理解）；用户调整后记住尺寸与位置，重启保留。
  - 2026-11-24 **人工确认**：回复**就地**在浮窗内容区切换为撰写，不回到主窗口 sheet。
  - 2026-11-24 **人工确认**：工具栏 = 回复 / 全部回复 / 转发（不加标记已读、删除、刷新）。
  - 2026-11-24 **人工确认**：远程图片**默认直接显示**，理由「打开了说明很重要，需要仔细看」；范围**仅浮窗**，主窗口仍默认阻止；浮窗顶部给一条静态提示，不弹确认框。
  - 2026-11-24 **人工确认**：打开浮窗**即标已读**；写失败语义沿用现状（本地失败提示、服务器回写失败静默）。
  - 2026-11-24 **人工确认**：撰写态下双击另一封**不替换**，只置前并提示。
  - 2026-11-24 **人工确认**：键盘入口 = 双击 + Enter + 空格三者等价。
  - 2026-11-24 默认（未经人工）：浮窗内会议卡只读无按钮；撰写编辑器仍阻止远程资源；宽下限 480pt、高下限 460pt；非当前选中邮件也可打开（按引用读取，见 `REQ-0032`）。
